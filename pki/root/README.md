# Brown Rook Root CA

Canonical root artifacts for governance and recovery documentation.

- Root certificate: `root_ca.crt` (PEM)
- Root CSR: `root_ca.csr` (public key + signature, no private key)
- OpenSSL extensions config: `root_ca.cnf`
- GnuTLS template: `root_ca.tmpl`
- Full ceremony log: `ceremony.log`
